# Level Up Fitness

A lightweight, beginner-friendly fitness app built for low-end Android phones and offline use. It has quest-based workouts, XP, coins, badges, streaks, a boss arena, and a simple mobile-first interface.

## Features

- Rebuild, power, and recovery workout plans
- Timer-based steps and breathing reset
- Progress tracking with XP, streaks, and coins
- Beginner-safe flow for people restarting after inactivity
- Mobile install support using a web app manifest
- GitHub Pages deployment workflow
